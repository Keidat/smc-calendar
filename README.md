# 세명 스쿨캘린더

세명컴퓨터고등학교 학생을 위한 학교생활 도우미입니다. 학사일정과 학급 일정, 급식을 달력으로 확인하고 일정별 댓글로 소통할 수 있습니다.

## 주요 기능

- 로그인 없이 학교·학급 일정과 급식 조회
- 전체·학사·학급 일정 필터와 날짜별 상세 보기
- 로그인 후 소속 학급 일정 등록 및 본인이 작성한 일정 수정·삭제
- 실명 댓글 작성·수정·삭제와 좋아요
- 고정 댓글 또는 추천 댓글을 일정 목록에 표시
- 학교 이메일 인증 회원가입과 아이디·비밀번호 로그인
- 개인정보 확인, 비밀번호 변경·복구, 회원탈퇴
- 이미지 첨부 문의와 사이트 알림함
- PC와 모바일 화면 지원

시간표와 채팅은 아직 구현하지 않았습니다. 화면과 댓글에는 실명을 사용합니다.

## 회원가입·로그인

1. 회원가입 화면에서 학생을 선택합니다. 교사 계정이 필요한 경우 관리자에게 문의하세요.
2. 아이디, 실명, 학교 이메일, 소속 학급, 비밀번호와 비밀번호 확인을 입력합니다.
3. 학교 이메일로 받은 인증 코드를 입력해 가입합니다.
4. 로그인에는 이메일 대신 아이디와 비밀번호를 사용합니다.

- 아이디는 영문 소문자·숫자·밑줄 4~30자이며 중복 사용할 수 없습니다.
- 비밀번호는 8~128자입니다.
- 사용 가능한 이메일 형식은 회원가입 화면에서 펼쳐 확인할 수 있습니다.
- 동일 학생의 두 학교 이메일을 이용한 중복 가입은 제한됩니다. 동명이인은 가입할 수 있습니다.
- 실명이나 소속 학급을 잘못 입력했다면 관리자에게 변경을 요청하세요.

비밀번호를 잊었다면 비밀번호 복구에서 가입한 아이디와 이메일을 입력하고, 이메일 인증 후 새 비밀번호를 설정하세요.

## 일정·댓글 사용 방법

- 로그인하면 학사일정과 소속 학급 일정이 함께 표시됩니다.
- 전체·학사·학급 필터와 학급 선택으로 표시할 일정을 바꿀 수 있습니다.
- 모바일 달력에서는 일정이 있는 날짜에 색 점과 일정 개수를 표시합니다. 파란색은 학사일정, 보라색은 학급 일정이며 현재 필터에 표시되는 일정을 기준으로 합니다.
- PC에서는 날짜를 누르면 해당 날짜의 일정 목록을 확인합니다. 모바일의 큰 달력 아래에는 DAY PLANNER 목록을 표시하지 않으며, 날짜 칸을 누르면 일정 목록 팝업이 열립니다. 달력 안의 작은 일정 글자를 눌러도 상세 화면으로 바로 이동하지 않습니다.
- 모바일에서는 팝업의 큰 일정 카드를 눌러야 상세 화면으로 이동합니다. 팝업은 닫기 버튼이나 바깥 배경을 눌러 닫을 수 있습니다.
- 일정 이름을 누르면 상세 화면과 댓글이 표시됩니다.
- PC에서는 작은 달력의 상단을 드래그해 네 모서리로 옮기고 테두리로 크기를 조절합니다.
- 확대 아이콘으로 큰 달력으로 돌아갑니다.
- 상세 화면에서 브라우저 뒤로가기를 누르면 큰 달력으로 돌아갑니다. 작은 달력에서 날짜를 바꿨다면 이전 날짜로 돌아갑니다. 앞으로가기도 지원합니다.
- 일정·댓글의 수정과 삭제는 PC의 우클릭 메뉴 또는 모바일의 `⋯` 메뉴를 사용하세요.
- 모바일에서는 오른쪽 아래 메뉴로 일정·급식·문의 화면을 이동합니다.
- 화면을 아래로 읽다가 위로 스크롤하면 SC 로고와 홈 아이콘이 있는 흰색 바가 내려옵니다. 홈 아이콘을 누르면 큰 달력의 전체 일정으로 돌아갑니다. 아래로 스크롤하거나 페이지 맨 위에 도달하면 바가 숨겨집니다.

댓글 조회·작성·좋아요는 로그인 후 이용합니다. 좋아요는 댓글별 한 번 누를 수 있고 취소할 수 있습니다. 수정한 댓글에는 `수정됨`이 표시됩니다. 대표 댓글은 고정 댓글이 우선이며, 없으면 좋아요를 가장 많이 받은 댓글이 표시됩니다. 대표 댓글 본문은 로그인하지 않은 사용자에게도 보일 수 있습니다.

## 급식

급식 달력에서 날짜를 선택하면 메뉴·칼로리·영양·원산지를 확인합니다. 모바일 달력에는 중식 등 급식 구분만 간단히 표시하고, 날짜를 누르면 상세 메뉴 팝업이 열립니다. 모바일에서는 달력 아래 상세 영역을 별도로 표시하지 않습니다. 팝업은 닫기 버튼이나 바깥 배경으로 닫습니다. 월 이름 양옆의 화살표로 월을 바꾸고 오늘 아이콘으로 현재 날짜로 이동합니다. 메뉴의 알레르기 번호는 원문 그대로 표시합니다.

공식 데이터: [나이스 급식식단정보 API](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17320190722180924242823&infSeq=2)

## 문의·알림

로그인 후 문의 메뉴에서 제목과 내용을 작성할 수 있습니다. 파일 선택 또는 붙여넣기로 이미지를 첨부할 수 있습니다.

- 최대 3장, 이미지 한 장당 2MB
- PNG·JPEG·GIF·WebP 지원
- 전송 전 미리보기와 첨부 취소 가능

문의는 사이트에 접수되며 이메일로도 전달됩니다. 이메일 전송 실패 안내가 나오더라도 사이트 접수가 완료되었다면 문의를 다시 작성할 필요는 없습니다. 문의 회신은 사이트 알림함과 가입 이메일로 전달됩니다. 외부 이메일에서 보낸 답장은 사이트에 자동 반영되지 않습니다.

알림함은 읽지 않은 메시지를 먼저 표시합니다. 남은 메시지가 없으면 “새로운 알림이 없습니다.”가 표시됩니다. 오른쪽의 **읽은 메시지 확인** 버튼으로 이전 알림을 확인할 수 있습니다.

## 개인정보·회원탈퇴

계정 아이콘에서 개인정보를 확인하고 비밀번호를 변경할 수 있습니다. 비밀번호 변경에는 현재 비밀번호·새 비밀번호·새 비밀번호 확인이 필요하며, 완료 후 모든 기기에서 로그아웃됩니다. 모바일의 로그아웃 버튼도 개인정보 화면에 있습니다.

회원탈퇴는 현재 비밀번호와 확인 문구 `회원탈퇴`를 입력해 진행합니다. 계정, 댓글·좋아요, 문의·첨부 이미지, 알림이 삭제됩니다. 공유 일정은 작성자 정보 없이 유지됩니다. 이미 발송된 이메일과 별도 보관된 백업은 탈퇴 기능으로 삭제되지 않습니다.

## 기술 구성

| 구분 | 기술 |
|---|---|
| 서버 | Python 3.13 이상, 표준 라이브러리 |
| 화면 | HTML, CSS, JavaScript |
| 데이터 저장 | SQLite |
| 이메일 | SMTP |
| 급식 | 나이스 Open API |

별도 Python 패키지 설치나 프론트엔드 빌드는 필요하지 않습니다. 현재 기본 웹서버는 개발·테스트용으로, 정식 운영에는 운영 환경 구성이 필요합니다. 서버 설치·회원 관리·백업 등 운영자 전용 안내는 공개 README에 포함하지 않습니다.

## 개발 검증

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
node tests/calendar_history.test.cjs
```

Node.js는 화면 코드 검사에 사용하며 앱 실행에는 필요하지 않습니다. 테스트는 임시 DB와 모의 응답을 사용합니다. 실제 이메일 수신과 PC·모바일 화면은 별도로 확인해야 합니다.

## 이용 중 문제가 생겼다면

- 화면이 갱신되지 않으면 브라우저에서 강력 새로고침(Ctrl+F5)을 해보세요.
- 인증·회신 이메일이 보이지 않으면 스팸함과 입력한 이메일 주소를 확인하세요.
- 일정·급식이 조회되지 않거나 개인정보 수정이 필요하면 문의 메뉴를 이용하세요.
- 비밀번호나 이메일 인증 코드는 문의에 첨부하지 마세요.
