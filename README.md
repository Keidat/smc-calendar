# 세명 스쿨캘린더

세명컴퓨터고등학교 학생을 위한 학교생활 도우미입니다. 학교 학사일정과 학급 일정을 함께 확인하고, 실명 댓글로 소통하며, 나이스 API에서 월별 급식을 조회할 수 있습니다.

Python 표준 라이브러리와 SQLite를 사용합니다. 별도 Python 패키지 설치나 프론트엔드 빌드가 필요하지 않습니다. 현재 실행 서버는 개발·테스트용이며, 인터넷에 정식 공개하기 전 운영 환경 구성이 필요합니다.

## 주요 기능

- **학교·학급 달력**: 로그인 없이 조회, 전체/학사/학급 필터, 학급 선택, 날짜별 상세 목록
- **일정 상세**: 중앙 일정 목록과 오른쪽 댓글, PC의 이동·크기 조절 가능한 작은 달력
- **일정 관리**: 학생은 소속 학급에 등록하고 본인 일정만 수정·삭제, 교사·관리자는 모든 일정 관리
- **실명 댓글**: 로그인 후 조회·작성·좋아요, 본인 댓글 수정·삭제, 수정됨 표시
- **대표 댓글**: 고정 댓글 우선, 없으면 좋아요가 가장 많은 댓글 표시
- **회원가입**: 학교 이메일 인증, 아이디 중복 확인, 비밀번호 확인, 학교 식별자 중복 가입 차단
- **내 계정**: 개인정보 확인, 현재 비밀번호를 확인한 뒤 비밀번호 변경
- **비밀번호 복구**: 가입한 아이디와 학교 이메일로 코드를 받아 비밀번호 재설정
- **문의함**: 이미지 첨부 문의, 관리자 조회·검색·미답변 필터·회신
- **알림**: 사이트 알림함과 이메일, 개인·선택한 여러 회원·전체 회원에게 발송
- **급식 달력**: 나이스 API에서 월별 메뉴·칼로리·영양·원산지 조회
- **모바일 화면**: 빠른 이동 메뉴, 터치용 수정·삭제 메뉴, 화면 크기에 맞춘 배치

시간표와 채팅 기능은 아직 구현하지 않았습니다. 닉네임은 사용하지 않으며 화면과 댓글에는 실명을 표시합니다.

## 빠른 시작

### 1. 준비

- Python 3.13 이상
- 최신 웹브라우저
- 실제 이메일 기능을 사용할 경우 SMTP 발송 계정
- 월별 급식 기능을 사용할 경우 나이스 API 인증키

Windows PowerShell에서 프로젝트 폴더로 이동합니다. 다른 경로로 복사한 경우 실제 경로를 사용하세요.

```powershell
cd C:\code\github_sky\smc-calendar
```

### 2. 개인 설정

처음 설정하는 경우 예제 파일을 복사합니다. **이미 `.env.local`이 있으면 덮어쓰지 마세요.**

```powershell
Copy-Item .env.example .env.local
```

`.env.local`에 실제 값을 입력합니다.

```dotenv
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-sender@gmail.com
SMTP_PASSWORD=your-app-password
SMTP_FROM=your-sender@gmail.com
HOST=127.0.0.1
PORT=8000
COOKIE_SECURE=0
NEIS_API_KEY=your-neis-api-key
```

위 계정·비밀번호·인증키는 설명용 값입니다. 발급받은 실제 값으로 바꾸세요.

| 설정 | 설명 |
|---|---|
| `SMTP_HOST` | 발송 메일 서버 |
| `SMTP_PORT` | `587`: STARTTLS / `465`: TLS |
| `SMTP_USER` | SMTP 로그인 계정 |
| `SMTP_PASSWORD` | SMTP 비밀번호 또는 Gmail 앱 비밀번호 |
| `SMTP_FROM` | 발신 이메일 주소 |
| `HOST` | `127.0.0.1`: 본인 PC 접속 / `0.0.0.0`: 다른 기기의 접속도 수신 |
| `PORT` | 서버 포트, 기본 `8000` |
| `COOKIE_SECURE` | 로컬 HTTP는 `0`, HTTPS 운영 환경은 `1` |
| `NEIS_API_KEY` | 나이스 API 인증키. 월별 급식 조회에 필요 |

이미 설정된 프로세스 환경변수가 있으면 `.env.local`보다 우선합니다. 설정을 변경하면 서버를 재시작하세요.

### 3. 실행

```powershell
python server.py
```

Windows에서는 다음 명령도 사용할 수 있습니다.

```powershell
.\start.ps1
```

브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)에 접속합니다. 종료하려면 서버 터미널에서 `Ctrl+C`를 누릅니다.

처음 실행하면 `server.py` 옆에 `school.db`가 생성됩니다. 현재 작업 폴더가 달라도 DB 위치는 프로젝트 폴더로 고정됩니다. DB를 새로 생성한 경우 회원·일정 데이터는 자동으로 복원되지 않습니다.

### 4. 최초 관리자 생성

새 DB에 관리자가 없을 때 사용합니다.

```powershell
python server.py --create-admin
```

운영자가 소유자를 확인한 허용 학교 이메일, 아이디, 비밀번호를 입력합니다. 이 명령은 운영자 전용 초기 설정이며 이메일 인증을 거치지 않습니다. 일반 회원가입은 이메일 인증이 필수입니다.

기존 DB를 옮기면 기존 관리자도 유지됩니다. 서버 실행만으로 계정을 초기화하거나 개발용 관리자 계정을 자동 생성하지 않습니다.

## 학교 설정과 회원가입

### 도메인과 학급

`config.json`은 로컬 학교 설정입니다. 실제 학교 편제에 맞게 학급 목록을 구성하세요.

```json
{
  "domains": ["smc.sen.hs.kr", "sonline20.sen.go.kr"],
  "classes": ["1학년 1반", "1학년 2반", "2학년 1반", "3학년 1반"]
}
```

예시 학급은 실제 전체 편제를 나타내지 않습니다. `config.json`이 없으면 `smc.sen.hs.kr`과 임시 학급 목록(1~3학년, 각 1~10반)을 기본값으로 사용합니다. 관리자 화면에서 이메일 도메인을 추가할 수 있습니다.

`관리자`·`교사` 학급 항목은 관리자 회원정보 수정 화면에만 표시됩니다. 공개 달력과 학생 회원가입 학급 목록에는 표시하지 않습니다.

### 가입·로그인 규칙

- 아이디: 영문 소문자·숫자·밑줄 4~30자. 입력한 아이디는 소문자로 처리합니다.
- 비밀번호: 8~128자, 확인 입력 필수
- 이메일 인증: 6자리 숫자, 10분 유효, 최대 5회 시도, 60초 재전송 간격
- 이메일·아이디는 중복 가입 불가
- 실명은 중복 허용: 동명이인 가입 가능
- 로그인은 **아이디와 비밀번호** 사용
- 교사 직접 가입은 차단하며 관리자에게 문의하도록 안내
- 소속 학급과 실명 등은 관리자에게 변경 요청

### 두 학교 이메일 간 중복 가입 방지

학교에서 안내한 이메일 규칙으로 공통 학생 식별자를 추출합니다.

| 이메일 예시 | 학생 식별자 |
|---|---|
| `24s209@smc.sen.hs.kr` | `24s209` |
| `24s209h0659@sonline20.sen.go.kr` | `24s209` |

같은 식별자는 DB의 UNIQUE 인덱스와 서버 검사로 중복 가입을 차단합니다. 식별자는 입학 시 정보이며 현재 학급 선택과 독립적입니다.

교사(`t`) 주소나 안내된 패턴 외 주소는 학생 식별자를 추정하지 않습니다. 새 도메인 추가 시에는 해당 도메인의 식별자 규칙도 별도로 구현해야 합니다. 기존 DB에서 식별자가 중복되면 자동 삭제하지 않고 관리자 확인이 필요하다는 오류로 중단합니다.

## 화면 사용 방법

### 일정·댓글

- 로그인하면 학사일정과 소속 학급 일정이 함께 보이는 전체 보기로 시작합니다.
- 날짜 선택 시 해당 날짜에 표시할 일정이 있으면 상세 내용을 읽기 좋은 위치로 스크롤합니다.
- 일정 이름을 누르면 일정 목록·댓글 화면으로 전환합니다.
- PC에서는 작은 달력 상단을 드래그해 네 모서리에 배치하고, 테두리·모서리에서 크기를 조절합니다.
- 작은 달력 확대 아이콘으로 큰 달력으로 돌아갑니다.
- 모바일에서는 오른쪽 아래 메뉴 아이콘으로 전체·학사·학급·급식 등의 화면을 이동합니다.
- PC의 수정·삭제는 일정·댓글 우클릭 메뉴, 모바일은 `⋯` 메뉴를 사용합니다.
- PC에서 같은 항목을 다시 우클릭하면 브라우저 기본 메뉴를 사용할 수 있습니다.

댓글 좋아요는 로그인한 사용자당 댓글별 한 번이며 취소할 수 있습니다. 대표 댓글은 **고정 댓글 우선**, 없으면 좋아요가 1개 이상인 최다 추천 댓글입니다. 동점이면 먼저 작성된 댓글을 표시합니다. 대표 댓글의 본문은 공개 일정 화면에서도 표시됩니다. 댓글을 실제로 수정하면 `수정됨`이 표시됩니다.

### 급식

월별 달력에서 날짜를 선택해 메뉴·칼로리·영양·원산지를 확인합니다. 학교 정보는 나이스 API에서 서울 소재 세명컴퓨터고등학교를 조회해 확인합니다.

- 월별 급식 조회에는 나이스 인증키 필요
- 정상 조회 결과는 서버 메모리에 1시간, 미등록 결과는 10분 캐시
- 급식 정보가 없는 경우와 API 오류를 구분해 안내
- 메뉴 뒤 괄호의 알레르기 번호는 원문 그대로 표시

공식 데이터: [나이스 급식식단정보 API](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17320190722180924242823&infSeq=2)

## 관리자 문의와 알림

### 문의·회신

학생·교사는 문의 작성, 관리자는 문의함 메뉴를 사용합니다. 관리자는 제목·내용·작성자 검색과 미답변 필터를 이용할 수 있습니다.

문의는 사이트 DB에 저장한 후 관리자 메일로 전송합니다. 이메일이 실패해도 사이트 접수 내용은 유지됩니다. 관리자 회신은 작성자의 사이트 알림함과 가입 이메일에 함께 전달됩니다. 외부 이메일에서 작성한 회신을 사이트로 자동 수집하는 기능은 없습니다.

### 이미지 첨부

- 파일 선택 또는 문의 창에서 이미지 붙여넣기(`Ctrl+V`)
- 최대 3장, 한 장당 2MB
- PNG·JPEG·GIF·WebP 지원, SVG 미지원
- 전송 전 미리보기·개별 삭제
- 관리자 문의함·회신 창에서 썸네일과 원본 확인
- 이메일에도 이미지 첨부
- 첨부 원본은 DB에 저장하며 작성자·관리자만 접근 가능

### 알림 발송

관리자는 전체 회원 또는 선택한 여러 회원에게 사이트 알림과 이메일을 보낼 수 있습니다. 수신자는 이름·아이디·이메일과 학급으로 검색하고, 페이지를 이동해도 선택이 유지됩니다. 회원 검색은 페이지당 30명입니다.

이메일 발송 내역에서는 최근 100건의 미시도·실패·SMTP 접수 상태를 확인합니다. 미시도·실패 건은 사이트 알림을 중복 생성하지 않고 이메일만 재시도할 수 있습니다. 자동 재시도는 없습니다.

**SMTP 접수 완료는 받은편지함 도착을 보장하지 않습니다.** 스팸함, 학교 수신 정책, 발송 제한도 확인하세요. 현재 이메일은 수신자별로 순차 전송하므로 다수 발송 중에는 시간이 걸릴 수 있습니다.

## 데이터 저장·백업·다른 PC로 이전

`school.db`에 회원, 일정, 댓글, 좋아요, 문의, 첨부 이미지, 알림 등이 저장됩니다. 별도 DB 서버가 필요하지 않습니다.

### 백업

```powershell
python backup.py
```

`backups/날짜-시간/`에 SQLite backup API를 이용한 DB 복사본과, 존재하는 경우 `config.json`을 저장합니다. 실행 중에도 DB 백업을 만들 수 있습니다. **`.env.local`은 백업에 포함되지 않습니다.**

### 다른 PC로 이전

1. 기존 서버를 `Ctrl+C`로 종료합니다.
2. 프로젝트 코드와 `school.db`, `config.json`, `.env.local`을 새 PC로 안전하게 복사합니다.
3. Python 3.13 이상을 설치합니다.
4. 복사한 프로젝트 폴더에서 `python server.py`를 실행합니다.

기존 PC와 같은 폴더 경로일 필요는 없습니다. `.env.local`이 없으면 SMTP·급식 인증키를 다시 설정해야 합니다. 두 PC의 DB는 자동 동기화되지 않습니다.

### 복원

서버를 종료하고 현재 DB를 별도 보관한 뒤 백업의 `school.db`와 `config.json`을 프로젝트 폴더에 복사합니다. `.env.local`은 별도로 복원합니다.

Git에서는 `school.db`, `config.json`, `.env.local`, `backups/`를 제외합니다. **Git 저장소를 복제하는 것만으로 운영 데이터와 개인 설정이 복원되지는 않습니다.**

## 학사일정 초기 데이터

```powershell
python import_school_2026.py
```

제공받은 2026학년도 학사일정을 추가합니다. 2026년 3월~2027년 1월의 날짜별 일정 70개이며, 같은 날짜·제목의 학교 일정은 중복 추가하지 않습니다. 기존 일정·회원정보는 삭제하지 않습니다. 검토용 파일은 `data/school-2026.json`입니다.

Node.js가 설치된 경우 JavaScript 문법도 검사할 수 있습니다. Node.js는 앱 실행에는 필요하지 않습니다.

## 자주 겪는 문제

| 증상 | 확인할 사항 |
|---|---|
| 코드·설정을 바꿨는데 이전 동작이 보임 | 서버 종료 후 재시작, 브라우저 `Ctrl+F5` |
| 같은 Wi-Fi의 다른 기기에서 접속 불가 | `HOST=0.0.0.0`, 서버 PC의 IPv4 주소와 포트, 방화벽, 기기 간 접속 차단 여부 |
| 외부 장소에서 내부 IP로 접속 불가 | 외부 접속용 HTTPS 주소·호스팅·터널 등 별도 구성 필요 |
| 사이트 알림만 오고 이메일은 오지 않음 | 관리자 이메일 발송 내역, SMTP 설정, 스팸함·학교 수신 정책 |
| 월별 급식 조회 실패 | `NEIS_API_KEY`, 외부 인터넷 연결, API 오류·한도 |
| 관리자 인증 실패 | 현재 로그인 계정의 관리자 권한과 비밀번호 |
| DB 이전 후 데이터가 없음 | 코드뿐 아니라 실제 `school.db`를 복사했는지 확인 |
| 동일 학생 식별자 중복 오류로 시작 불가 | 기존 중복 계정을 관리자 확인 후 정리. 자동 삭제하지 않음 |

## 정식 배포 전 준비

현재 Python 기본 HTTP 서버는 개발·테스트용입니다. 정식 공개 전 아래 작업이 필요합니다.

- 운영용 웹서버 구성과 HTTPS 적용
- 개발용 관리자 비밀번호 변경
- HTTPS 환경에서 `COOKIE_SECURE=1` 설정
- SQLite 파일을 보존하는 영구 저장소와 백업·복원 점검
- SMTP·나이스 API 외부 통신이 가능한 배포 환경 확인
- 여러 사용자의 동시 접속과 이메일 대량 발송 처리 개선
- 실제 브라우저·모바일·역할별 사용 흐름 검증

소스코드·공개 문서·스크린샷에 `.env.local`, 인증키, 앱 비밀번호, 실제 회원 DB를 포함하지 마세요. 문의 이미지도 개인정보를 포함할 수 있으므로 DB 백업과 전달 경로를 관리해야 합니다.
